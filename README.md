# ⚽ Votação do Melhor do Mundo 2026

Aplicação web desenvolvida como trabalho prático para a disciplina de **Desenvolvimento Web**.

O objetivo do projeto é criar um sistema interativo onde os usuários podem votar no jogador de futebol que consideram o melhor da temporada, visualizando a apuração dos votos e o ranking em tempo real.

---

## 📋 Funcionalidades

- **Votação em Tempo Real**: Cada voto computado atualiza a contagem, as porcentagens e a barra de progresso do atleta.
- **Pódio (Top 3)**: Exibe os três jogadores mais votados (1º Ouro, 2º Prata e 3º Bronze).
- **Filtro por Posição**: Botões para filtrar jogadores por Atacantes, Meio-Campistas, Defensores ou Goleiros.
- **Barra de Pesquisa**: Busca dinâmica por nome, clube ou país do jogador.
- **Ordenação**: Opção para ordenar por mais votados ou por ordem alfabética.
- **Cadastro de Novos Jogadores**: Modal simples para adicionar novos atletas à disputa.
- **Persistência de Dados**: Uso de `localStorage` para manter os votos e novos jogadores salvos no navegador.
- **Zerar Votação**: Opção de reiniciar a contagem com confirmação.
- **Design Responsivo**: Funciona em computadores, tablets e celulares.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Layout responsivo com Flexbox, CSS Grid e variáveis CSS.
- **JavaScript (ES6)**: Manipulação do DOM, eventos e persistência com LocalStorage.
- **Google Fonts**: Fontes *Montserrat* e *Open Sans*.
- **Font Awesome**: Ícones da interface.

---

## 🚀 Como Executar o Projeto

1. Abra a pasta do projeto no seu computador.
2. Dê dois cliques no arquivo `index.html` para abrir diretamente no navegador.

Se preferir usar um terminal PowerShell:
```powershell
Start-Process index.html
```
